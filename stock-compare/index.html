Rules, data & scoring

We fetch historical prices from Fintable’s public stock endpoints. Both stocks are compared on their first and last shared trading dates; the exact dates appear before you choose. Return = (last adjusted close ÷ first adjusted close − 1) × 100. Historical windows end before today.

Correct answers earn 100 points, plus 25 for each prior win in the current streak, capped at a 100-point bonus. A wrong answer earns 0 and resets the streak. Returns equal to two decimal places are a tie: either pick counts as correct. Retrying a failed API call costs no points.

The provider documents split- and dividend-adjusted history. IEX is a single-exchange feed, so values can differ from consolidated market data. Past returns do not predict future results. This game uses historical performance, not current prices; latest quotes remain in the comparison tool.

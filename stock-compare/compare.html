How the comparison works

Both series use only dates available for both tickers. Each starts at $100: value = 100 × adjusted close ÷ first adjusted close. Return is the change between the first and last shared dates. Fees and taxes are excluded.

Volatility is the sample standard deviation of daily percentage returns, multiplied by √252. It describes past fluctuations, not future risk. If the API omits different dates for each ticker, volatility is unavailable rather than treating multi-day returns as daily returns. Maximum drawdown is the largest decline from a previous peak within this window.

The API provider documents split- and dividend-adjusted history. IEX data covers one exchange, so prices and volume can differ from consolidated market data. This is an educational comparison, not a live quote or investment recommendation.
